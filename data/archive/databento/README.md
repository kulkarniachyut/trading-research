# Databento archive — paid-for CME futures bars, banked once

This folder is the **durable, committed** copy of the Databento data we have spent free-tier credits
on. It exists so that **no workspace, clone, or teammate ever re-fetches (and re-pays for) the same
bars.** Backtests read this archive offline — they never hit the network and don't even need the
`databento` package installed.

## What's stored
- **Canonical 1-minute bars only**, as zstd-compressed Parquet, tz-aware in `America/New_York`.
- Every higher timeframe (5m / 15m / 1h / D1 / …) is **derived locally** from the 1m series at read
  time (`src/data/resample.py`). One stored series ⇒ all timeframes, and adding a timeframe costs
  zero credits.

## Layout
Bars are **chunked one Parquet file per calendar year** (each ~3–5 MB) so no single file grows large
and git diffs stay small; a year file is immutable once written. `read_1m` concatenates a symbol's
year files transparently.
```
data/archive/databento/
  manifest.json                     # coverage index (start/end/rows per symbol), regenerated by data_pull
  reference/<symbol>/<year>.parquet # burned IS/OOS years (<= 2024) — read freely, e.g. 2017.parquet
  holdout/<symbol>/<year>.parquet   # reserved final holdout (2025+) — SEALED
```

## Holdout discipline
Years `>= 2025` route to `holdout/` and are **not read** unless a caller explicitly passes
`allow_holdout=True` (`DatabentoProvider(allow_holdout=True)`). Banking the holdout data now (while
credits exist) is *not* peeking — but the scope split makes accidental peeking structurally hard. Do
not point a tuning run at the holdout.

## How to (re)populate it — `scripts/data_pull.py`
The **only** code that spends credits. Dry-run by default (prints a cost estimate, moves no data):
```bash
uv sync --extra data                                          # needs the databento package + DATABENTO_API_KEY in .env
uv run python scripts/data_pull.py --years 2021-2024          # estimate cost only
uv run python scripts/data_pull.py --years 2021-2024 --yes    # download + archive (reference)
uv run python scripts/data_pull.py --years 2025-2026 --yes    # bank the sealed holdout
```
It is idempotent — already-archived years are skipped, so re-running is free.

> `*.parquet` is globally git-ignored; a negation in `.gitignore`
> (`!data/archive/databento/**/*.parquet`) makes only this archive commit.
