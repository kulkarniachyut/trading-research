## The highest-value, codeable rules (extracted across all 68 — start here for the redesign)
The decks converge on one thesis and a handful of precise, testable rules. See `DECK_NOTES.md` for
the per-deck detail; this is the shortlist that should drive the Tier 1→3 redesign.

1. **TIME × PRICE is the whole edge (Ep 39).** A setup fires only when a PD array (FVG/OB/old level)
   is reached **at a key macro time**. Our mechanical model checked price arrays *continuously* with
   no time gate — that is *why* it was noise. **Gate every entry on macro times: 00:00 (MNO), 08:30,
   09:30, 10:00, 13:30** (also the times SMT divergence is valid — Ep 35).
2. **Narrative/bias is a prerequisite, stand-aside is a first-class output (Ep 19, 24, 39).** No
   confident HTF bias ⇒ no trade. Don't loosen the displacement requirement to manufacture trades
   (anti-overfit guardrail; "setup not forming = missed move, not a broken model").
3. **Daily Rebalance Theory = the bias/draw engine we're missing (Ep 25, 19, 37).** On a major
   weekly/daily high/low being taken, look at the **last 3 days**: FVG present ⇒ draw rebalances it;
   no FVG ⇒ use PDH/PDL and rebalance the prior day's move. **Purge & revert** (purge day = day 1).
   Validate liquidity *sequence* (bearish ⇒ BSL taken first, else invalidate).
4. **MNO / 08:30 anchor + heavy-discount read (Ep 17, 19, 38).** Pick the anchor: if MNO is no longer
   "in play" vs price@0830, use 0830. Price still below both at 0830 on a bullish day = heavy discount
   (prime long); needs a 5m/15m **MSS** to trigger.
5. **MSS requires a prior sweep + displacement that leaves an FVG (Ep 3, 23, 33).** Run *through* a
   level *with* an FVG = continuation; **sweep + reject** = reversal. Big run with *no* FVG/pullback =
   just a sweep ⇒ stand aside (Ep 36).
6. **FVG quality is quantifiable (Ep 29, 22, 9).** Take the gap only if it sits **above 50% of the
   displacement leg** (buys) / below (sells); prefer gaps whose **candle bodies** (not wicks) respect
   the edge; invalidation only on a **body close** through it; an FVG containing a swing low is higher
   quality (swing = trigger + stop).
7. **OB validity = it created an imbalance after it; reference = open + 50% mean-threshold (Ep 18, 13,
   35).** MT body-close-through ⇒ OB fails. Not every down candle is an OB.
8. **Premium/discount is a contextual gate, not a mechanical reversal (Ep 22).** Above an old high =
   short-term premium array, below an old low = discount — but price needn't pull back; must align
   with narrative. Target *unmitigated* draws, not already-swept levels.
9. **News/regime = catalyst, not filter (Ep 23, 29, 30, 36).** High-impact days: expect **initial →
   another → fake-out → real** leg sequence (arm later). Pre-FOMC-speak day = narrow-range regime.
   NFP week (1st of month): be done by **Wed 08:30**. FOMC AM tradeable but be flat before release.
   Fib anchor: bodies in low-vol, **wicks in heavy news**.
10. **Day-type regime switch (Ep 32, 38).** Outside day ⇒ next day consolidation ⇒ **fade the EQ
    edges**, expect a 15:00 MOC volatility burst (don't run the breakout model). Bullish-day template:
    AM rally → lunch consolidation → PM SSL sweep → rally (deviations re-route the PM plan).
11. **SMT is timed, biased confirmation that *selects the symbol* (Ep 7, 22, 29, 35).** Check ES↔NQ /
    SPY↔QQQ only at the macro times, only with a bias; trade the **stronger** (non-confirming) leg.
12. **Confluence (Tier 3) & risk (Ep 41, 25).** "FVG + OB + OTE after a short-term MSS is golden."
    Trail in stages: 50% of target ⇒ stop to 25%; 75% ⇒ BE (BE only after swing-mitigation).
